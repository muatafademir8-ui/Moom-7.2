# MOOM Retro FPS Engine for PSP / PPSSPP

Bu paket, PSP ve PPSSPP emülatörleri için geliştirilmiş olan **MOOM** retro FPS oyun motorunun kaynak kodunu ve derleme dosyalarını içerir.

## İçindekiler
- `main_5.c`: Ana oyun motoru ve Raycaster mantığı.
- `Makefile`: PSPSDK ile EBOOT.PBP derleme yapılandırması.

## Derleme Talimatları
1. Sisteminizde PSPSDK kurulu olduğundan emin olun.
2. Terminal üzerinden proje dizinine gidin.
3. `make` komutunu çalıştırarak `EBOOT.PBP` dosyasını oluşturun.
